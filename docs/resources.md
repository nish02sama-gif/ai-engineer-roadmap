# Resources

Mostly free. Websites change, so if a link moves, search the title. Prefer official docs first, then structured courses, and use videos as a supplement.

## Python and tooling

- Python official tutorial: docs.python.org/3/tutorial
- CS50's Introduction to Programming with Python (Harvard, free): cs50.harvard.edu/python
- Automate the Boring Stuff with Python (free online): automatetheboringstuff.com
- Kaggle Learn, "Python": kaggle.com/learn
- pytest docs: docs.pytest.org

## Git and GitHub

- GitHub Skills: skills.github.com
- Pro Git book: git-scm.com/book

## Data libraries

- Kaggle Learn: Pandas, Data Visualization, Intro to SQL (kaggle.com/learn)
- pandas "10 minutes to pandas": pandas.pydata.org/docs
- NumPy "absolute beginners" guide: numpy.org/doc

## Machine learning

- Kaggle Learn: Intro to Machine Learning, Intermediate Machine Learning
- scikit-learn user guide and tutorials: scikit-learn.org
- Machine Learning Specialization (Andrew Ng, Coursera, can audit free)
- StatQuest (YouTube) for intuition on statistics and ML concepts

## NLP and deep learning

- Hugging Face courses: huggingface.co/learn
- fast.ai Practical Deep Learning: fast.ai
- 3Blue1Brown "Neural networks" series (YouTube) for intuition
- Andrej Karpathy "Neural Networks: Zero to Hero" (YouTube), optional and challenging

## LLMs, RAG, agents

- Claude documentation and Anthropic Console: docs.claude.com
- Anthropic courses on GitHub: github.com/anthropics/courses (prompt engineering, tool use)
- DeepLearning.AI short courses: deeplearning.ai/short-courses
- Sentence Transformers docs: sbert.net

## Deployment

- FastAPI tutorial: fastapi.tiangolo.com/tutorial
- Docker "Get started": docs.docker.com/get-started
- Hugging Face Spaces for free demo hosting: huggingface.co/docs/hub/spaces

## Practice

- Kaggle datasets and competitions for beginners: kaggle.com
- Neetcode (neetcode.io), easy Python array/string/hash-map problems for interview practice. Keep it to a small side habit, about 3 problems a week.
